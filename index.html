How it works. Each TapeOut processor on X Layer is an ERC-721 contract; every circuit (NFT) exposes circuitInfo(id), a combinational eval(id, input) and a sequential step(id, state, input). TruthTable calls them for every input (and every latch state), fingerprints the result and matches it against a reference library — so an AI agent or a buyer can check a circuit before relying on it. Reads go from your browser directly to the X Layer RPC; nothing is stored or signed.

Honest limits. Official TapeOut ABI docs were not found; selectors and the circuitInfo word order were derived from live bytecode and behaviour. Truth tables are capped (≤ 8 inputs; ≤ 6 state+input bits) to stay polite to public RPCs. The X Layer factory is an upgradeable proxy controlled by its owner — results describe the code live at read time.
